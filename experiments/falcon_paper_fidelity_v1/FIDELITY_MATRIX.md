# FALCON 论文一致性边界

这个目录用于新的、隔离的 FALCON DNN 复现。旧数据集、旧模型和旧的 25 维实验都不会被覆盖。

## 论文明确给出的部分

| 项目 | 本实现 |
|---|---|
| DNN 输入 | `[p_g-p, r_g-r, v, v_dot]`，12 维 |
| DNN 输出 | `[F, wx, wy, wz]`，4 维 |
| MPC 预测步数 | `K=20` |
| 控制/采样周期 | `0.05 s`（20 Hz） |
| 教师数据规模 | 10 个随机初始状态 × 40 个环境 × 5 s ÷ 0.05 s = 40,000 条 |
| 数据划分 | 80% / 10% / 10% |
| DNN | 全连接 Linear + ReLU |
| 六种结构 | depth `{10,22,34}` × width `{512,1024}` |
| 学习率和轮数 | `1e-4`，20,000 epochs |
| 关卡 | 5 个门；相邻门 y-z 曼哈顿位移使用 epsilon `{0,0.8,1.6}` |

## 论文没有公开、必须显式补全的部分

| 未公开项 | 本实现的可审计选择 |
|---|---|
| 作者 ACADO 生成代码及完整参数 | CasADi 非线性 MPC，使用论文动力学；权重和约束采用公开 `uzh-rpg/rpg_mpc` 默认值。它不是作者二进制的逐位复刻。 |
| 多项式边界条件 | 每周期从当前 `p/v/a` 到当前门后 1 m 重新拟合五次多项式。 |
| 参考速度 | 固定 5 m/s，这是用户指定的实验速度，不是论文公开数值。 |
| 10 个随机状态的范围 | 在配置文件中完整记录位置、姿态和真实初速度范围。 |
| 40 个关卡的随机种子/具体坐标 | 固定种子 2025，并保存全部门坐标。 |
| 随机拆分的单位和种子 | 按完整 episode 随机拆分，种子 2025，避免相邻时刻泄漏。 |
| optimizer、batch size、初始化 | Adam、batch 1024、Kaiming hidden/Xavier output；全部写进运行命令和 checkpoint。 |
| 是否归一化 | 输入和输出都只用训练集统计量做标准化；论文未说明此细节，物理单位 MSE 与 normalized training loss 会分别保存。 |

因此，这个实验可以称为“严格遵守公开协议、对未公开细节做显式假设的复现”，不能声称是作者 ACADO/PAMPC 可执行程序的 bit-exact 复刻。

## 防止一对多标签的方法

12 维输入没有“期望速度”字段。因此 `paper_core_40k` 不会逐 episode 随机改变参考速度。规划器的 5 m/s、加速度上限、门后距离等参数在整个数据集中固定；未来 20 步参考轨迹由当前 12 维状态和这些固定参数唯一生成。实际速度 `v` 和加速度 `v_dot` 仍会随飞行变化，并不是所有样本都等于 5 m/s。

## 防止旧版撞门问题的方法

- DNN 输入始终相对“当前尚未穿越的门中心”，不是相对一个会提前跳变的临时 waypoint。
- 只有轨迹线段真正由门前穿到门后，并且交点位于净开口内，才切换到下一门。
- 轨迹终点在门后 1 m，规划器会引导飞机穿过门平面，而不是只到门中心。
- 初始速度通过 AirSim `simSetKinematics` 真正写入，不再只写进 JSON 却没有作用于仿真。
- 任何碰撞、越界、门外穿越、NaN 或严重周期超时都会使该 episode 失败，不会保存成“成功教师数据”。

这些措施消除了已经定位出的数据/切门错误，但不能数学保证任意 DNN 永不碰撞。最终仍必须以未见关卡闭环通过率和门内穿越偏差验收。

## 两类数据必须分开报告

- `paper_core_40k`：只用于复现论文 40k 协议和 Table II 六模型比较。
- `recovery_extension_60k`：独立采样偏航、横向/高度偏差、高速和组合边界状态，每条都重新规划并重新调用 MPC。它用于提高闭环恢复能力，不能算作论文原始 40k 数据。

二者合并后生成 `dnn_dataset_robust_100k`，其结果必须标注为“robust extension”，不能拿来冒充 Table II 的严格复现数字。
