# Windows IP37 黄金验证、实时影子飞行与输入范围复现

## 已验证的链路

Windows 通过 UDP 5237 连到 AXU3EGB 的 IP37/1 服务。两个模型各 32 条黄金样本全部通过，最大 INT8 参考误差分别为 4.32e-8、4.74e-8。报告在 `results/ip37_windows_live_20261106_20261106_213715/`。原交付客户端在本机使用的计时钟把 RTT 记录成 0 或 16ms，因此这里只采用黄金输出证据。新增的 [ip37_shadow.py](../../../controller_architecture_study/ip37_shadow.py) 复用已核验的编解码器并使用 `perf_counter_ns` 计本机 RTT。

另外，从已有 AirSim 恢复实验取了 20 个校准组的不同原始 237D 输入，按原采集逻辑取状态特征的前 237 项。每个输入分别发给两个模型，40 条全部返回。FP32 对照使用部署 manifest 对应的同一源权重与归一化。小模型、大模型的最大 `body_rate_x` 差值分别为 0.066 和 0.748 rad/s。样本来自一批历史校准状态，差值用于识别部署误差，不当作模型恢复资格。报告在 `results/ip37_airsim_archive_20261106_20261106_214502/`。

## 三机实时影子结果

环境 48、路线 0、50ms 错峰。MPC 生成并下发控制，随后向独立的有界 IP37 镜像队列提交同一条原始 237D 输入。返回的四维控制只记录。每轮 3 架均穿过 5 门。原始请求与报告在 `results/ip37_airsim_live_20261106_20261106_214727/`。

| 影子模型 | 请求 | 返回有效控制 | 输入越界拒绝 | 成功项 RTT P99 | 成功项计划释放到板端结果 P99 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 11，4×1024 | 1200 | 1164 | 36 | 2.796ms | 25.011ms |
| 6，33×1024 | 1200 | 1165 | 35 | 14.292ms | 35.372ms |

这两轮的失败全部是 IP37 状态 3，每条一个通道越界。成功项的计划释放到板端结果最大分别为 29.379ms 与 38.365ms。这里的释放到结果时间包括采样、前端、MPC 与提交顺序产生的等待，终点是影子结果就绪，尚无 DPU 控制真正生效时间。

## 可复现的量化问题

复跑定位到第 8 个输入 `x[7]`，即第一个参考点相对于当前位置的 x 分量。采集轮在同一路线保留了 [37 条原始拒绝向量](../../local/controller_architecture_study/results/ip37_airsim_range_inputs_20261106_20261106_215102/ip37_rejected_inputs.json)。该文件 SHA-256 为 `e2d4b5868adaa681d573397591555c39256aec66c122448eb171f23ac901d641`。这批输入的 `x[7]` 从约 0.998m 到 1.272m，按当前模型的归一化与 input scale 16 换算，峰值约 163.33，超过板端正向拒绝阈值 128。

把这 37 条同一份原始向量分别发给现有的两个模型，74/74 次都重现了状态 3。逐条复现记录与拒绝输入在同目录。将 input scale 8 仅作为候选做离线可表示性计算，37 条均落入范围。实际量化图、推理输出与闭环质量尚需用候选构建实测。

Ubuntu 下一轮可使用这批 raw237 向量复现并评估候选量化。保持 FP32 权重和外部特征契约，保留原模型包。优先制作小模型候选，核对校准数据和编译后实际输入比例，再对原黄金、这 37 条向量及独立正常输入比较物理输出误差。随后按相同的三机影子流程确认原越界区间有有效返回。大模型对同源 FP32 的明显差异也应单列，不以黄金通过替代实际输入的数值验证。

## Windows 复跑入口

保留板端 IP37 服务，AirSim 使用手动 Play。以下命令只把 MPC 控制下的在线输入镜像到板端：

```powershell
Set-Location -LiteralPath 'F:\FalconReproduction\airsim_control'
$env:PYTHONDONTWRITEBYTECODE = '1'
$py = 'D:\files\PYTHON\cv_lab\Yolov8_Beginner_Demo-main\.venv\Scripts\python.exe'
$bundle = 'F:\FalconReproduction\237D_data\board_237d_timing_20261106_pair_run001\board_237d_timing_20261106_pair_run001'
$out = '.\controller_architecture_study\results\ip37_live_recheck_' + (Get-Date -Format 'yyyyMMdd_HHmmss')
& $py -u -m controller_architecture_study.probe_airsim_three --mode shadow --model residual21x1024 --device cuda --phase staggered --preprocess-policy vectorized --environment-id 48 --route-index 0 --period-ms 50 --deadline-ms 50 --ip37-bundle $bundle --ip37-model-id 11 --output-dir $out
```
