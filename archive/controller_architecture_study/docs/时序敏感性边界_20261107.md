# 当前时间敏感性证据的边界与下一步

## 十个实飞周期点没有显示明显快周期优势

用户已完成 `teacher_period_sweep_20261107_190128` 和 `teacher_period_sweep_20261107_191116`，gain7固定、同一2.1m自然路线，无注入延迟。

30～120ms、每10ms共10个点全部13门、零碰撞。全程位置RMSE约0.1190～0.1230m，没有明显随T缩短改善的趋势。补点六组时序均通过；30ms旧组存在漏周期。平均R约5.5～6.9ms，没有随周期被系统性改变成几十毫秒。因此这不是T与R两个变量的完整实验，不能得出“控制对响应时间不敏感”。

当前结果只支持：这个控制器＋这条路线＋小响应延迟，在已测周期区间具有较大容忍度。不能反推增益可无限增大，也不能保证其他任务时延条件下安全。增益3.5在原弯道下跟踪不足，增益7改善了它，仍不是所有增益/周期组合的普遍结论。

## 新增独立R轴离线诊断

没有让用户继续盲目实飞。复用此前验证过的理想角速度模型，固定gain7、T=120ms、同case；只把总采样至命令作用延迟设置为7、25、50、80、100ms。每组R都小于T，不用任务普遍超过周期来制造失败。模型无电机/阻力/量化/主机抖动，也不模拟碰撞后停机。

| 模拟R | 离线全程位置RMSE | 最小抽样膨胀门框余量 |
|---|---:|---:|
| 7ms | 0.0825m | +0.327m |
| 25ms | 0.0815m | +0.345m |
| 50ms | 0.0854m | +0.376m |
| 80ms | 0.1040m | +0.385m |
| 100ms | 0.1480m | +0.307m |

R=100ms比7ms的RMSE约增加79%，但几何余量仍为正；25ms甚至略优于7ms，单门余量也未随R单调恶化。应停止预设“所有指标严格单调”。这些是5条离线轨迹，不是AirSim新试飞或板端安全保证。

脚本、轨迹和逐项报告：`results/teacher_delay_offline_20261107_v1/run.py`、`report.json`。教师、场景、主循环及旧模型没有修改。

## 时延区间的硬件依据与限制

读取实际板端双模型报告 `F:/FalconReproduction/237D_data/board_237d_timing_20261106_pair_run001/RESULTS.md`：小模型服务均值约1.323ms，大模型约11.777ms。

假设8条大模型请求同时就绪，由单一执行器串行服务，最后一条的服务累计约94.2ms。这个排队算例不含PS预处理、网络和命令下发，也不是新增8机实测；仅说明80～100ms不是完全脱离现有硬件成本的诊断区间。新教师尚未训练为这些DNN，不能把板端旧模型精度与新教师能力混为一谈。

## 当前更可能的实验限制

1. 单机CPU教师服务快，实际R一直很小；没有形成多机资源竞争。
2. 参考平滑、已知，教师每次看到完整2秒参考；不是每次只看眼前下一个门。参考可预测性可能降低对频繁重新采样的需求，但其具体贡献尚未独立消融。
3. 当前控制器在该路线有明显余量；全通过只说明没有跨过碰撞边界，不代表位置性能完全相同。
4. 碰撞是较粗的二元指标，应同时保留连续误差、最小余量与实际延迟。当前R模型已经有性能差异，却没有安全失效差异。

## 下一步应如何收敛

不继续细分当前周期，不降低增益制造脆弱教师，不立即重训DNN。先固定这套正常控制器，离线考察代表性任务的变化时间尺度与真实可达R的关系，再决定是否值得上AirSim。

一个可解释的候选设计是沿同一空间路径做时间缩放：`p_alpha(t)=p(alpha*t)`，速度按alpha、加速度按alpha平方变化。门的位置不根据失败轨迹移动，不加突发扰动；必须先检查参考速度、加速度、倾斜与执行器能力，避免再次走进“快配置和慢配置都根本跟不上”的场景。这个候选尚未实现或获得收益证据。

核心资格是：现实可达到的快配置能稳定完成，现实共享计算可能产生的慢/旧控制有明显损失；这不是要求每一个T点都单调改善。若合理且代表性的工况在板端实际可达时间区间仍不敏感，就不能用它证明动态安全调度的必要性，应承认该基准不适合，而不是无限搜索个别有利样本。

文献对照：[Cervin等，How Does Control Timing Affect Performance?](https://portal.research.lu.se/en/publications/how-does-control-timing-affect-performance/)将采样与执行/通信延迟纳入仿真；不把它当成本工程一定存在明显收益的保证。
