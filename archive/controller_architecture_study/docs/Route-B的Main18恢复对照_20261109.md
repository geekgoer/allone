# main18 小／大模型等时延闭环对照

本轮比较旧 `main18_plain_mlp_h4_w1024_seed0` 和 `main18_plain_mlp_h33_w1024_seed0`。使用交接包中的 FP32 检查点和共享 237D 归一化，逐项核对登记哈希。研究问题是在控制命令到达时刻一致时，大模型是否带来可以辨认的恢复收益。

采用已用过的 `env48/route1` 弯道窗口，起点参考相位约 5.9355 s，净门宽 2 m。对照包括名义初态及三个世界 y 方向初始速度偏移 −0.6、−1.0、−1.45 m/s，三个扰动组都加 −0.05 m 初始位置偏移。每组共用初始状态、保持命令、3 s 窗口、50 ms 采样和 20 ms 采样至施加延迟。初始条件预算估计分别为 150、150、111.4、81.9 ms，均大于首条命令的 20 ms。该预算依赖项目现有条件假设。每组交换模型运行次序。

## 理想动力学预筛

四组每个模型各施加 60 条命令，两侧的采样和施加时刻逐条完全匹配。用理想机体角速度跟踪积分推进位置与姿态，报告的是几何模型下的采样门框余量和轨迹误差。5 ms 和 2.5 ms 步长复算结论一致。
