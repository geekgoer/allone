# 异质多机与快速危险段实验：修订方案

状态：已完成异质十机、单机碰撞退出、20候选选型及初批配对实飞。实现与全部结果见[实现记录](HETEROGENEOUS_IMPLEMENTATION_20261028.md)；不把此前同质统一配置或当前有限搜索称作全局最优。

## 已从代码和数据核对的事实

1. 旧起点采用0～2.1秒参考相位差。各机不但位置不同，启动阶段速度也不同。静态／动态配对中的初态匹配，不能消除这种设计对多机实验代表性的限制。
2. 旧长路线把相同路线平移到每条航道，并搜索所有飞机共用的模型和周期。它没有搜索异质任务下逐机的配置向量。
3. 旧暂停调用`simPause(True)`，会停止整个AirSim，未满足“只停碰撞无人机”的要求。
4. 当前237D输入含未来21步的相对参考位置、参考姿态、相对参考速度，以及20步参考推力特征。改变轨迹时间参数可以改变期望速度，不必每次重训。旧12D缺少参考速度的限制不能套用到237D。
5. 当前训练集元数据：实际速度约0～8m/s，当前参考速度约0～6.91791m/s。这只是边际范围，不保证任意速度／加速度／姿态组合均已覆盖。
6. 旧D路线末段相邻门距离约8.272、11.241、11.194、10.873m；主要曲线段时长约2.17～2.31秒。60ms时每段仍有约36～39次更新。固定60ms安全不是异常。
7. 规划器会搜索更长的段时间以满足速度／加速度上限。只缩短门距、增大横向变化，不检查实际轨迹时间，可能只得到更慢的轨迹。

## 研究假设与边界

要验证的是：不同回路的计算需求随状态／时间变化，共享资源又不足以让全部回路长期使用最昂贵的配置时，在线重分配是否能减少局部危险，同时保持任务性能。

“离线平均J最优不一定安全”是待测假设，不意味着离线一定碰撞。资源宽裕时，强固定配置也可能全程安全；已知危险路线也可能得到足够保守的逐机固定配置。不能通过排除安全强候选制造结论。

## 十机异质场景

| 飞机 | 路线类型 | 目标 |
|---|---|---|
| Drone1～3 | 连续起伏／转弯，强度和转弯相位各不相同 | 长期较高控制需求 |
| Drone4～8 | 直线或轻微曲线 | 低需求回路，提供可回收的计算余量 |
| Drone9～10 | 平缓段后进入连续急弯，危险开始时刻不同 | 需求突然增大，检查在线资源转移 |

- 使用同一出生横截面、相同高度、相同初始速度、相同到第一门的距离；各航道保持横向隔离。默认首门前有足够的真实接近距离。
- 取消物理参考相位差。计算请求需要错峰时，单独记录release offset，不靠把飞机放到不同物理位置实现。
- 危险时刻来自固定路线，不在飞行中推飞机、移门或修改状态。
- 以门距、横向／竖向变化、参考速度定义参数化场景族；记录实际速度、横向加速度、曲率和通过各门的参考时间。
- 首先使用已有训练范围内的5m/s标称速度，再探索4、6m/s。不把提高速度等同于直接放大DNN的四维输出。
- 更难路线必须仍可由足够及时的参考控制器通过。若所有及时控制器都失败，不作为动态调度能救回的证据。

## 静态基线：二十次全局配置评估

每个候选是完整向量`{(model_i,T_i)} + priority_order`，允许不同无人机有不同模型、周期和固定优先级。

- 总预算为20个全局候选评估，含初始配置；不是20次重启、每次另做大量搜索。
- 固定随机种子和邻域规则。每次调整一架飞机的模型或周期，或者交换一对固定优先级，保留预测总J更好的可行配置。
- 在预算内保留最优值和完整搜索轨迹；名称为“20次有限预算局部搜索所得最好静态配置”。不称数学全局最优，也不称完整FALCON复现。
- 静态和动态采用同一硬件域、时延统计口径和容量条件。不能因静态一次偶发超期删掉强候选，却忽略动态更多超期。
- 离线选型只使用校准场景／预测性能，最终危险段复核使用另行冻结的场景种子。不能看完动态结果再倒选静态基线。

## 快速模式：缓存重复段成本，真实运行关键段

允许把长任务改为用于搜索的近似评估，但必须保留三个边界：

1. 缓存与模型、周期、路线类型、参考速度、共享负载及模型／归一化版本绑定。不能把一个轻载配置的平缓段成绩套给所有配置。
2. 进入危险段前保留至少一个完整预测窗口和恢复接近段。当前未来窗口长约2秒，实际建议保留3～4秒真实接近飞行，使速度、姿态和未来参考自然衔接。
3. 这是缓存段与实飞段的拼接估计，不是完整连续长路线实飞。跳过部分的成功、零碰撞和边界状态正确性不能靠成本缓存证明。最后选少量代表场景做完整复核。

对Drone4～8和Drone9～10前段，可以测若干重复平缓片段；对Drone1～3，应测代表性重复曲线片段，不能把它们的困难前段也计作平缓飞行。

现有评分是21点窗口误差和的平均值取倒数，再对飞机求和。缓存每段窗口数和窗口误差成本，不缓存一个可以直接相加的J。

若重复前段有`n_easy`个窗口、实测平均窗口成本为`E_easy`，危险段有`n_hard`个窗口、实测窗口成本和为`S_hard`，则：

```
J_hat_i = (n_easy + n_hard) / (n_easy * E_easy + S_hard)
J_hat_total = sum_i J_hat_i
```

此式仅适用于当前已经声明的跨窗口聚合口径。段界应对齐完整评分窗口，避免重复计数或遗漏跨段窗口。保存重复测量的波动范围，并检查静态排名是否对缓存误差敏感。

## 碰撞处理

- 演示中只停撞机：取消该机后续控制输出，单机制动／悬停；其他飞机、仿真时钟和记录继续运行。
- 若需要严格保持接触位置，可以在碰撞发生后固定该机状态，明确标记为失败后的显示处理；该机碰撞后的数据不再作为正常控制性能。
- 不调用全局`simPause`作为多机正常碰撞处理。
- 碰撞机后续是否退出推理服务必须对两组采用同一规则，并记录活跃任务数。退出后释放的资源会影响其余飞机，不能隐瞒这一变化。
- 已碰撞并停止的飞机没有完整任务J。报告任务失败／缺失，不能用碰撞后的悬停轨迹、短时窗成绩或虚构补齐值计算正常全程J。
- 离线预测J、缓存拼接J和完整实飞J分别标注。碰撞率来自真实关键段，不从缓存推断。

## 执行顺序与必要检查

1. 修正异质世界、等距离起点、逐机配置接口及单机碰撞退出；以两机小检查确认撞机停止、另一架仍有后续位移与命令。
2. 修正动态释放的全局可行性。上一轮12机动态实际命令空窗达86.8ms，固定40ms约53.3ms；单纯收紧请求周期和改前端排序都未解决，不能先忽略它去增加几何难度。
3. 建立短片段缓存和20候选有限预算搜索，输出每个候选的逐机配置、预测总J、资源占用与可行性依据。
4. 运行异质危险段静态／动态配对：相同路线、初态和资源，真实记录碰撞及其余无人机继续飞行。
5. 按预先规定的难度与负载档位，在多个冻结种子上统计碰撞率、完成率、期限失约及J，而非只挑某个成功救回例子。
6. 选择少量代表场景做完整飞行，核对快速拼接估计和危险段初态近似是否改变结论。

成功标准是一个场景族中可重复的收益。若更强静态同样安全，或者动态在负载下更不稳定，保留负结果并修正实现或研究假设，不强行产生正例。
