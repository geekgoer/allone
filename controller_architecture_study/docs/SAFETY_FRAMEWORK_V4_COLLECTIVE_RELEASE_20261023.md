# 八机安全框架比较：v4 全局释放规划

## 当前结论

目前尚未取得“FALCON 风格静态基线碰撞，而动态框架完成任务”的有效证据。v3 的静态局部搜索找到八机正常完成的配置，但动态正常工况未通过，所以不能解释为安全性收益。

基线不是完整 FALCON：固定 CPU、三个冻结的 237D 模型、六种周期与有限邻域，使用实测等权总 J 选择；没有 SVM、完整硬件搜索或原文全部权重。J 使用原文公式形式，但 Wx=I10。

## v4 改动及不变项

每次新控制发送完成后，对所有尚未释放的下一任务统一按绝对截止时间排序，计算累计完整任务成本与最小余量，共同移动释放时刻。保留 10ms 派发余量；无估计余量时立即按 EDF 工作，不延长物理截止时间，也不声称已通过准入分析。此前各机独立推迟释放可能相互挤占，已经替换。

完整任务成本包含状态 RPC、特征、IPC、推理和控制发送；来自静态正常工况 p95 加余量，不是 WCET。一次只允许一个完整任务在途，两种策略一致。代码支持层分段，但本实验不声称发挥了层内抢占优势。

不改变模型、权重、归一化、净门宽、初始状态族、物理预算公式或过期输出拒绝规则。距离/速率预算只是启发式，不是 CBF 安全证书；发送后 ping 返回时间只是命令生效时间的代理。

## 连续执行步骤

1. 单元回归：IPC 非阻塞、累计 EDF 可行性与截止时间不变、函数分段一致性等。
2. 明确导入 v3 静态搜索及其哈希；配置必须重新正常试飞，不能直接把历史成功算作本轮成功。
3. 同配置动态正常试飞；不通过则停止扰动结论，保留失败。
4. 通过后自动运行全部 16 个预声明扰动状态、两策略交替顺序的 32 次配对飞行。
5. 若发现静态碰撞而动态完成且双方无时序违规的案例，再做三个新的邻近初始状态重复，并加入最快正常静态配置对照。
6. 全部结果（包括负结果）保存，清理本实验门框、解除暂停；不操作编辑器屏幕。

场景是八架真实仿真无人机、各自相隔 12m 的门组，净宽 2m、高 4m；每次固定 3 秒，预期穿过两扇门，不等于完整五门任务。AirSim 启动配置含 12 架，但本实验只激活八条控制回路。

判定不能把停止、悬停、拒绝过期命令或缺失任务窗口视为安全完成。搜索发现只提供有限场景证据，不构成全局最优或安全保证。
