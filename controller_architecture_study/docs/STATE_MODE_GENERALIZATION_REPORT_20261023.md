# 跨参考上下文验证：117次新增试验及本阶段结论

日期：2026-10-23。本文是**已实际执行的结果**，不是待执行计划。

## 1. 先看结论

本轮的阶段性成果是定位了经验状态表不能直接泛化的两个缺口，而不是证明超网必须存在：

1. **参考在QP约束内，并不保证当前教师闭环满足跟踪要求。** 两个新转弯上下文中，教师从名义位置/速度/姿态出发，50ms下也不满足末段持续跟踪。这不能解释为小网络算力不够。
2. **相同`h,h_dot`不对应通用合格周期，初始姿态的作用也不单调。** 新参考中−30°初始滚转组通过，无姿态扰动的配对组失败；这与旧参考上的125ms结果不同。
3. **仍未发现稳定的大子网恢复优势。** 不能把较低离线模仿MSE直接当成状态相关最低计算需求的证据。
4. **25ms补充诊断受Windows/RPC时序污染，不能用于排除更短周期。** 失败和中止均保留，不补跑到通过为止。

因此，本轮没有继续开发通用State-to-Mode表、在线周期接管器或新增FPGA模块。它们需要的能力前提尚未由当前结果支撑。这不是说超网不能部署、原FALCON结论错误，或任何任务都不需要大模型。

## 3. 新上下文如何选定

原数据划分：train环境0–47，validation环境48–53，test环境54–59。新试飞使用validation环境49、50，原先边界试验使用环境48。

在飞行前冻结三个上下文：`(49,1,0.30)`、`(49,1,0.55)`、`(50,2,0.40)`。第三项是区间`[1.5s, duration−3.3s]`的固定比例，不按神经网络成败或最大曲率再选点；结果出来后没有更换路线。

| 上下文 | 环境/路线 | 保存轨迹相位 | 3s参考速度范围 | 最大参考倾角 | 名义QP预测约束激活 |
|---|---|---:|---:|---:|---:|
| ctx0 | 49/1 | 3.78556s | 4.879–5.734m/s | 29.568° | 0/61查询 |
| ctx1 | 49/1 | 5.69019s | 4.879–5.663m/s | 29.568° | 0/61查询 |
| ctx2 | 50/2，含高度变化 | 4.61140s | 4.915–5.475m/s | 25.856° | 0/61查询 |

这是**三个参考上下文、两条路线、两个环境**，不是三个独立环境，也不是未用于模型选择的最终test评估。相对于上一轮单参考相位，是跨上下文检查；不能把确定性模拟器内重复当成总体可靠性样本。

每个恢复上下文均有`h=1m,h_dot=−0.4m/s`，横向位置偏差约0.55m。两个姿态条件是`q_ref`及`q_ref*q_roll(−30°)`；位置、速度、旧控制和参考相位相同。三个周期不改变物理初态。

名义对照另将位置/速度/姿态全部对齐参考。**所有条件的初始角速度、线加速度均统一置零**，旧命令为参考推力＋零角速度；所以名义对照不是整条动态轨迹的严格稳态，也不是所有动力学状态均无误差。

## 4. 主批次111次的完整统计

| 指标 | 结果 |
|---|---:|
| 原“窗口中曾持续恢复”控制判据 | 87/111 |
| 加上末段持续跟踪 | 19/111 |
| 持续控制与时序联合通过 | 15/111 |
| 时序可比 | 94/111 |
| 发送前硬截止期过期 | 0次 |
| 共同交付目标偏差 | 57个命令事件，分布于部分trial |
| RPC返回晚于截止期 | 3个命令事件 |
| 报告碰撞、越界或其他error | 0/111 |
| 观测到的最小h | 0.56854m |

“持续跟踪失败”不等于撞门、撞地或完全不能飞。原判据允许窗口中先恢复，后又出现跟踪误差；持续判据用于避免将这种情况直接标成可部署能力。

更大CPU网络较多出现共同目标偏差，相关trial保留而不用于能力差异归因。RPC返回不是精确命令生效确认，不能据此声称不存在执行接口不确定性。

### 4.1 两个新转弯：教师名义对照已不达标

T=50ms、p/v/q与参考对齐时：

| 上下文 | 末段最大位置误差 | 末段最大速度误差 | 持续跟踪 | 时序可比 |
|---|---:|---:|---|---|
| ctx0 | 0.93617m | 1.18808m/s | 否 | 是 |
| ctx1 | 0.71425m | 0.99768m/s | 否 | 是 |
| ctx2 | 0.26883m | 0.59586m/s | 是 | 是 |

ctx0、ctx1各36次恢复对比都未满足末段要求；教师在这两个上下文的所有13次试验均时序可比。因此，不能把这里的失败都推给神经网络推理延迟，也不能认为继续增大DNN就能自动修复。

另一方面，“最大参考倾角不超过35°、QP约束不活跃”只是有限的可行性检查，并非考虑姿态响应、保持控制和闭环瞬态后的轨迹跟踪证书。

### 4.2 同一h/h_dot，初始滚转影响反转

ctx2恢复试验的**末段持续控制判据**结果如下。三种控制器在每一行的二元结果一致；各自时序通过情况另见热图的`T`标记和CSV。

| 初态 | 50ms，每控制器 | 100ms，每控制器 | 125ms，每控制器 |
|---|---:|---:|---:|
| 无相对姿态扰动 | 0/2 | 0/2 | 0/2 |
| 相对滚转−30° | 2/2 | 2/2 | 2/2 |

旧环境48参考相位中，小子网125ms无姿态扰动3/3、−30°滚转0/3；本轮ctx2小子网125ms正好相反，而且该125ms小子网配对的时序均可比。

这支持“姿态/参考上下文影响合格条件”，不支持“姿态偏差越大必然越难”。偏差方向、未来参考变化和动态误差抵消/叠加可能参与其中；目前没有做足以识别唯一机制的控制消融。

也不能仅据此给表多加一个“姿态危险等级”就称问题解决，更不能将两个已测周期之间全部插值为合格。

### 4.3 仍没有可确认的大子网能力收益

108次恢复形成36个同初态/同周期/同重复的三控制器匹配组：

- 20组所有控制器时序可比。
- 在这20组中，“最大子网通过而最小子网失败”为0组，反向也为0组。
- 其中只有2组同时满足教师持续通过及所有时序可比；这2组大小子网也均通过。

所以结论是**当前没有发现大模型必要性**，不是“36组都有效地证明了所有模型等价”。教师合格且时序充分可比的样本仍少，不能证明任意状态下不存在大模型收益。

六个新初态的同输入查询中，最大子网5/6更接近教师，另1个初态反而稍差，不能声称它处处更优。例如ctx2无相对姿态扰动时，小/大子网归一化控制MSE为0.0110115/0.0000823955，但三种周期下两者持续控制都未通过；ctx2滚转组为0.0335991/0.000111778，两者却都通过。

这些是有限初态上的离线输出差异，不是整个数据集MSE，也不能单独预测闭环品质。

## 5. 离线诊断：参考的角速度需求与教师标签不一致

对精确参考p/v/q作61次名义查询，比较参考姿态运动学角速度与教师输出角速度，单位rad/s：

| 上下文 | 三维差值范数最大值 | 三维差值范数均值 |
|---|---:|---:|
| 旧环境48参考相位 | 1.1972 | 0.3015 |
| ctx0 | 2.4773 | 0.7614 |
| ctx1 | 2.5415 | 0.6816 |
| ctx2 | 1.9250 | 0.5564 |

当前教师以QP首步加速度生成期望姿态，再使用`3.5 * rotation_error`生成角速度，没有直接使用planner的body-rate前馈。源码有明确说明：planner姿态和QP优化后姿态不完全相同，不能不加分析就把planner rates直接相加。

这些查询说明：即便在精确参考p/v/q上，当前标签也不完全重现参考的姿态运动学；新上下文的不一致更大。这是**教师/参考匹配需优先检查**的线索，但不是已证明“缺少前馈是所有飞行误差的唯一原因”，也没有因此修改控制器或训练标签。

若后续改变教师控制律，需要独立版本、独立教师试飞，并重新生成对应标签；不能悄悄改live教师却继续声称旧超网模仿的是同一函数。

## 6. T=25ms诊断：明确记录未成功的验证

全部三个上下文各2次名义教师试验，保持原20ms交付目标，只将period从50改25ms。

- 6次均时序不可比；5次覆盖完整3s，1次在发送前硬截止期过期，拒绝下发该过期输出并退出。
- 记录12个RPC晚返回事件；即使命令在deadline前发出，晚返回也不能证明精确生效时刻合格。
- 完整窗口的控制数值仍呈现ctx0/ctx1不通过、ctx2通过，但**不能作为严格的25ms对50ms控制效果对比**。
- 提前结束的trial保留原始轨迹；派生CSV将未覆盖的末段和完整窗口RMSE留空，不把早期小误差伪装成3s跟踪良好。

此诊断给出的结论是当前20ms目标＋25ms周期在本Windows/RPC测试协议下没有取得可比验证，不是不存在更短可用周期、教师频率提高没有价值，或FPGA做不到。

本轮没有临时修改计时容差、deadline、系统计时器或发送目标再反复试到通过。

## 7. 当前Go / No-Go与下一步

| 项目 | 判断 |
|---|---|
| 原最小模型、教师、超网资产 | 保留，未改变；旧已测条件的结果仍有效 |
| 固定最小子网作为强对照 | 保留；但不是未覆盖状态的安全fallback |
| 无条件`[h,h_dot] → mode/period`通用表 | **No-Go：已有跨上下文反例** |
| 立即做在线自适应接管原型 | 暂缓；不能把不合格或未覆盖条件自动映射为合格 |
| “大子网必要、136配置有效、无切换震荡” | 尚未被本轮证明 |
| FPGA已有工程工作 | 本轮不修改；可独立推进，但不能将其工程进展替代能力收益证明 |

建议下一步只做一项优先工作，而不是新增模块：**先明确可接受的任务参考族，并确认教师在这些参考上满足独立的任务要求。**

可以选择保留当前教师并限定其经验证的适用参考族；若目标确实需要急转弯，则应在新分支修正教师/姿态参考跟踪，再验证教师。二者是研究任务范围的选择，不宜为得到“大模型更好”的曲线随意更改。

教师及任务要求固定后，再用少数代表子网作同状态、同响应条件的能力对比。有稳定且可利用的模式差异，再进入状态相关模式选择；只有时序收益，则优先固定廉价控制器＋更新时间适应，并重新核对与已有自触发控制工作的区别。

此处不自动增加在线DNN误差预测器、高维LUT、RL、复杂QoC模型、全局搜索或新的硬件分区。参考适用性是实验和声明的前提，不要求为了它另造runtime实体。

本轮已到阶段性停止点：不为了正结果继续选路线、改阈值、重复二分或追加训练。
