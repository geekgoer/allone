# B 的理论修改建议：在失去恢复能力以前完成控制更新

日期：2026-10-29。状态：研究方案，尚未修改运行控制代码，尚未验证其对完整无人机模型的适用性。

## 1. 要解决的问题与不变的框架

用户要求提前识别具有动力学依据，不能通过任意缩小 B、添加距离阈值来制造静态失败而动态成功的结果。保持现有 Safety Analyzer → 模型选择/释放规划 → 有限抢占调度结构，不加入独立的 DNN–MPC 误差模块。

原来的 B_geo=d/v_bar 在 d 为净安全间隙、v_bar 确实约束整个保持窗口内的接近速度时，是单窗口不触边的充分条件。它并非错误，但没有自动保证：窗口结束后，仍有可实现的控制和可行的计算服务来恢复系统。

拟修改的对象是 Safety Analyzer 内部用来定义安全余量的集合：从“尚未碰撞”收紧为“仍处于某个已建立恢复能力的区域”。这属于控制不变集、有限输入约束、递归可行性等经典问题的应用，不能把制动距离本身称为新贡献。

当前代码还有独立限制：safe_horizon 是 gate-slab/rate 启发式，存在门前 3 m 检查范围和 150 ms 截断；analyze_budget 记录实际保持控制，但明确标记 uses_control_in_bound=false。不能把当前实现等同于用户完整理论推导，也不能仅替换一个距离项就宣布已经实现严格安全分析。

## 2. 独立考虑的候选与取舍

| 候选 | 优点 | 局限/决定 |
|---|---|---|
| 固定系数 alpha·B 或距离预警线 | 实现简单 | 无法解释提前量，容易只是增加计算频率；不作为理论修改 |
| 根据当前速度/加速度求首次碰撞时间 | 比只用距离更贴近保持控制的运动 | 仍可能在碰撞前已经失去恢复能力；可作为对照 |
| 用恢复区域定义保持控制的允许时间 | 提前量由控制能力和动力学产生，可连接 Yang safe period | 需要明确恢复区域与实际控制能力；推荐方向 |
| 在线完整可达集/HJ 或优化恢复轨迹 | 表达能力强 | 求解和验证开销较大，第一版不采用 |

## 3. 一个可明确推导的局部模型

先只考虑朝某个固定侧向边界运动的一维局部模型：

\[
\dot d=-v,\qquad \dot v=a.
\]

- d：扣除机体尺寸与规定余量后的净距离，单位 m。
- v：朝该边界的有符号接近速度，单位 m/s；正值表示接近。
- a：接近速度的变化率，单位 m/s²。
- b>0：一个指定、实际可用的恢复控制，在整个相关恢复过程内能够保证的减速度下界。不是硬件峰值，不是日志中最好的一次减速度，也不能由 DNN 的 MSE 推断。

在理想加速度控制模型中，若恢复时可施加 a=-b 直到 v=0，然后维持不接近边界，所需制动距离为 v_+²/(2b)，其中 v_+=max(v,0)。定义

\[
\rho(d,v)=d-\frac{v_+^2}{2b},\qquad
\mathcal K=\{(d,v):\rho(d,v)\ge0\}.
\]

在上述局部模型和可实现恢复策略的假设下，K 是一个可保持不触及该边界的区域；它不是完整无人机穿门问题的最大可生存集。

若新控制生效前，当前保持控制产生的运动满足整个窗口内 v_+≤v_bar、a≤a_bar，取 a_bar≥0，则 v>0 时

\[
\dot\rho=-v\left(1+\frac a b\right)
\ge-\bar v\left(1+\frac{\bar a}{b}\right).
\]

v≤0 时 rho_dot=-v≥0，同一损耗上界仍成立。因此，当 rho≥0、v_bar>0 时，一个保持在 K 内的充分等待上界为

\[
B_{rec}(x)=
\frac{d-v_+^2/(2b)}{\bar v(1+\bar a/b)}.
\]

证明只需积分：rho(t+s)≥rho(t)-v_bar(1+a_bar/b)s。对所有 0≤s≤B_rec，rho 均非负。与使用同一个 v_bar 的 B_geo=d/v_bar 相比，B_rec≤B_geo。

这是一种保守闭式构造，不是精确最大等待时间。a_bar 若不区分已经在纠偏的保持控制，会过于保守；后续可利用实际 u_k 和动力学得到更紧的轨迹界。

直观特例：保持阶段 a=0、v>0 不变，则

\[
v\tau+\frac{v^2}{2b}\le d
\quad\Rightarrow\quad
\tau\le\frac d v-\frac{v}{2b}.
\]

例如 d=0.30 m、v=1 m/s、b=2 m/s²：制动已经需要 0.25 m，留给等待的距离仅 0.05 m，因此允许等待 50 ms，而非仅依据 d/v 得到的 300 ms。这是说明公式的假想例子，不是对当前 AirSim 数据拟合得到的参数。

当 rho<0，含义是“该局部恢复策略与能力假设不能给出证书”，不能推出所有控制器都不可能成功；更不能把 B 截成 0 后声称立即更新就保证安全。探索试飞可继续记录，但必须标记不可认证，而不是因缺少证书自动当作成功或要求新增硬编码中止。

## 4. 怎样对应真实 UAV 和 Yang 2019

真实指令是推力/机体系角速度，不能假设指令生效就立即获得 -b 的侧向加速度。姿态、角速度、推力限制、执行器响应都影响恢复轨迹。第一版理论示例只证明上面的局部模型结论；应用前必须把这些因素包含在状态/动力学或保守恢复轨迹内。

门框仅存在于有限纵向范围，不能在整个航线把某个门洞侧边当成无限延伸的墙。可在已定义的局部接近走廊内建立充分条件；更准确的版本需结合纵向到达时间与真实门框膨胀几何。恢复区域的定义与当前参考/任务阶段必须一致；轨迹转弯时需要相对速度和参考坐标系变化，而非直接套世界系侧向速度。

抽象定义可以保持简单：令 K 是在实际可用控制策略和模型假设下建立的恢复区域，定义保持当前实际控制的可达集合 Reach，则

\[
B_{rec}(x_k,u_k,\Omega_k)
=\sup\{\tau:\ \operatorname{Reach}_{u_k}(s,x_k,\Omega_k)
\subseteq\mathcal K,\ \forall s\in[0,\tau]\}.
\]

实际实现返回该量的可证明下界。必须检查整个保持区间，不能一般性地仅检查终点；也不需要在线求最大可生存集。K 可以是一个离线建立、保守且容易计算的内部集合。

Yang–Belta–Tron 2019 的 Definition 4 定义了固定保持控制下的 safe period，III.C 用轨迹界下界化 ECBF 约束并计算允许保持时间。可将恢复区域对应的约束作为其分析对象，但需要重新满足对应动力学、初始条件、可行控制等假设。Yang 原文已经处理高相对阶约束，并非只能保证一个点的几何间隙；不能声称这里通过“加入速度”就超越该文。

不显式加入 DNN 相对 MPC 的误差变量：保持阶段用实际已经下发的 u_k。仍须核对所选后续控制器是否有相应恢复能力。知道模型里存在一个可行刹车输入，并不代表任意一个 DNN 会输出它。该要求归入现有 controller admissibility，不新增独立误差模块。

## 5. 时间含义与资源接口

最直接的物理条件是

\[
a_{k+1}-a_k\le B_{rec}(x(a_k),u_k),
\]

其中 a_k 是实际控制生效时刻。若 T_k 是相邻任务的释放间隔、R_k 是释放到生效的完整响应时间，则精确关系是

\[
a_{k+1}-a_k=T_k+R_{k+1}-R_k.
\]

在这些时间定义下，现有形式 T_k+R_{k+1}^{ub}≤B_rec 是一个保守充分条件，不应误写为控制生效间隔的恒等式。若预算在更晚的新观测时刻计算，应使用正确观测时刻的状态和绝对期限，不重置之前已经承诺的期限。

仍由原调度框架选择下一 job 的 T、c，并进行全局准入及分段有限抢占。R 必须包括前端、排队、分段阻塞、计算和命令下发。新 B 不会自动消除这些开销；若实际可用资源下最快的合格控制器也赶不上预算，应明确判为不可行。

单次条件不自动证明无限时域递归可行。递归保证还需要：初态在有效集合内、后续所选控制能保持该集合、所有回路承诺可被实际服务、时延/动力学界成立。经验 p95 不能代替硬上界。

## 6. 哪些是经典内容，哪里可能形成论文贡献

以下均已有大量研究，不能单独作为创新：制动距离；速度相关安全集合；CBF/HOCBF；保持控制下的 safe period；资源感知 self-triggered MPC；状态驱动的多控制任务调度。

值得检验的研究命题是：共享有限抢占加速器上的神经控制，是否需要将“在物理碰撞前完成本次计算”提升为“在失去恢复能力前完成下一次合格控制，并保持其他回路的服务可行性”；能否以较低开销实现这种约束下的周期、控制器模式和调度联合调整。

具体差异需要落实到：神经控制器能力不单调；不同模式需要不同计算时间；多个回路竞争同一个非任意抢占的加速器；端到端响应依赖其他回路。不能只把已有安全控制方法换成 FPGA 平台就宣称理论创新。上述命题是研究方向，不是本次有限检索已证明的新颖性结论。

## 7. 后续最小工作集

1. 明确局部门框/走廊约束和可实现的恢复策略，先建立一个足够简单的恢复区域；若无法建立可用的控制能力下界，就不能把闭式示例冒充 UAV 证书。
2. 仅更换 Safety Analyzer 内部的集合与保持时间计算，保留现有框架接口，不新增另一套并行危险分数。
3. 对相同自然飞行路线、初态和模型，比较几何预算、一个预先固定的收紧系数、恢复预算。记录何时开始要求更快更新、何时离开恢复区域、门框接触和完整 J。
4. 用相近总推理次数/资源占用的对照，排除“仅仅多算了很多次”的解释；再做共享资源对照，核对是否把其他回路推入不可行。比较 B 计算开销与端到端尾延迟，不只看平均值。

先回答恢复预算是否有额外解释力，再决定是否实现更复杂的可达集或完整 CBF。此文档没有启动训练、试飞、修改运行参数或硬件设计。
