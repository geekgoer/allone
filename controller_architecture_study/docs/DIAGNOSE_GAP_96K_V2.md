# 96k / 300D 容量实验：Train–Validation gap 诊断

## 结论

最强证据指向：联合恢复状态的样本外泛化不足，而不是整个 DNN 没学会飞行，也不是简单的验证路线范围越界。
大网络已在正常跟踪、切段、制动、姿态恢复上降低了验证误差；总体指标却被少数困难联合恢复样本，尤其 yaw 角速度输出，主导。
延长 epoch 可能继续改善，但当前没有证据说明仅延长 epoch 能消除 gap。
不修改原数据、划分、归一化、教师配置或已有权重；不读取 Test，不启动训练或 AirSim。

## 1. 验证误差分解

以下均为使用相同 Train 归一化的控制输出 MSE，越低越好。

| Validation 类别 | 4×128 | 4×1024 |
|---|---:|---:|
| 正常跟踪 | 0.001557 | 0.000860 |
| 切段 | 0.001648 | 0.000820 |
| 制动 | 0.000631 | 0.000168 |
| 姿态恢复 | 0.004736 | 0.002217 |
| 组合恢复 | 0.162315 | 0.206428 |
| 全部类别 | 0.029516 | 0.036399 |

每个类别占验证集 12.5%，但组合恢复贡献全部误差的 68.74% / 70.89%。
4×128 的误差最大的 1% 样本贡献 49.03% 的总误差；4×1024 为 55.10%。
不是仅一个验证环境异常：4×1024 六个验证环境的 MSE 均在约 0.0293–0.0406。

按输出分解，`wz` 贡献标准化总平方误差的 84.09% / 86.39%。
这是标准化后的贡献，不能把物理单位 m/s² 与 rad/s 的平方直接相加解释为同一物理误差。
Train 的输出标准差为 `[4.074231, 1.778011, 1.950869, 0.651310]`；总体归一化来自全部 Train，而不是每类单独归一化。
不应仅为了得到更好看的曲线而降低 yaw 的损失权重。

## 2. 最有区分力的实验：已见路线上的新状态

在 16 条原 Train 路线上，用相同采样器和新随机种子独立抽取 128 条组合恢复状态，重新调用同一个 MPC 得到标签。
没有把这些数据加入训练，没有更改模型；采样中有 8 次拒绝后重采。
这些路线已有的 160 条组合恢复训练点与新点的结果：

| 模型 | 原训练点 MSE | 同路线、新状态 MSE |
|---|---:|---:|
| 4×64 | 0.047462 | 0.182003 |
| 4×128 | 0.017761 | 0.185169 |
| 4×1024 | 0.002908 | 0.232522 |

因此，仅“换成没见过的路线”不能解释 gap：路线不变，状态组合换了，大模型误差同样明显增加。
这是小规模、限定类别的诊断，不是全部路线的泛化证明，也不是新增正式 Validation/Test。

## 3. 数据丰富度不等于联合覆盖密度

当前 Train 有 960 条参考轨迹、每轨迹 80 条状态。
八类均衡分配，所以每条轨迹只有 10 条组合恢复状态，整个 Train 共 9600 条。
组合恢复同时变化位置 3 维、速度 3 维、姿态扰动 3 维，还叠加轨迹相位与未来参考窗口。
单轴范围覆盖充分，不代表这些变量的联合组合被充分覆盖。

按已保存的状态重建扰动后，组合恢复的实测统计如下：

| 统计量 | Train | Validation |
|---|---:|---:|
| 各扰动坐标进入外侧 30% 范围的比例 | 50.29% | 49.99% |
| 每行 9 个坐标中处于该范围的平均个数 | 4.53 | 4.50 |
| 至少 5 个坐标同时处于该范围的行比例 | 51.0% | 49.17% |
| 位置误差范数中位数（m） | 0.875 | 0.878 |
| 速度扰动范数中位数（m/s） | 1.735 | 1.735 |
| 姿态扰动旋转向量范数中位数（rad） | 0.291 | 0.291 |
| 至少一个 MPC 输出触及限幅的比例 | 90.74% | 91.0% |

30% 是每个坐标额外边缘采样的概率，均匀部分也会进入边缘，因此最终约一半坐标处于外侧范围。
由此，组合恢复并不是少量偶发的强扰动，而是经常同时施加强位置、速度和姿态扰动。
限幅本身不证明标签错误；但当前统计显示，高误差主要落在此类困难状态。
4×1024 的 saturated / unsaturated Validation MSE 分别为 0.090309 / 0.001553。
仅裁剪 DNN 输出，总体 MSE 从 0.036399 降为 0.034932，改善约 4%，不足以单独解决问题。

## 4. 已排查的替代解释

- Train/Validation 轨迹 ID 无交集，各几何类别和状态类别数量平衡。
- 数据源 manifest 哈希与 prepared split 匹配，模型来自同一份数据。
- 归一化使用 Train；重算均值与实际 float32 推理均值的最大差异为约 4.64e-7，属于存储精度差异。
- 300D 中仅局部位置原点 3 维恒零，这由契约设计决定，不是意外缺失状态。
- Validation 只有 20/9600 行越出 Train 的逐维 min/max；这不能证明联合覆盖充足，但不支持“大量验证输入数值越界”的解释。
- 同类样本近邻诊断：组合恢复的 Train 跨路线近邻标准化 RMS 距离中位数约 0.471，Validation→Train 为 0.505；没有出现非常大的整体距离跃升。该距离度量不是控制敏感性的严格度量。
- 重建 4×1024 高误差的 16 条组合恢复样本，重新查询 MPC：与保存标签的最大差异 2.861e-6，重复查询差异全为 0。此抽查不支持明显的标签串位、求解历史污染或 float32 舍入导致的大误差。
- 固定问题、冷初始化、KKT 合格与可重复，不等于证明非线性 MPC 的唯一全局最优解或所有扰动状态可安全恢复；这些仍未验证。

## 5. 训练方面的限制

九个模型都跑到了 400 epoch 上限，不是被 patience=80 提前停止。
多数最佳 epoch 位于后期，尤其 4×64=399、2×256=400、4×512=400、4×1024=396。
不能声明全部结构已经充分收敛；大模型较早把训练 MSE 降低，但 Validation 下降较慢。
训练代码使用 Adam、固定 1e-4 学习率，没有 weight decay 或学习率衰减。
这是值得做小规模对照的训练因素，不是已经证明的唯一根因。
即使 Train MSE 降得很低，也不能据此预测未见联合恢复状态的误差。

## 6. 建议的下一步（尚未实施）

### 优先级一：增加联合状态的有效覆盖，而不只是增加路线

保留当前 Validation/Test 和全部困难评估项。
先在 Train 路线上补 2–4 万条针对性独立查询，而不是再生成大量正常直线飞行样本。
优先包含：

1. 位置+速度、位置+姿态、速度+姿态这类双因素组合。
2. 完整组合扰动的连续幅值尺度，从正常状态逐渐到满幅；减少训练新样本各坐标同时贴边的比例，同时保留边缘样本。
3. 在 Train 中 MPC 输出接近限幅切换、模型误差较高处增加局部邻域采样，重新求 MPC 标签，不沿用旧标签。
4. 参考相位不变、轨迹不变的多状态样本，提高同一局部参考附近的状态密度；全局 C2 时钟不重置。

可以先保留现有归一化用于小对照，让模型暖启动和结果比较不同时受到归一化改变影响。
这些是候选方案；需通过固定评估验证，不能预先保证大模型排序翻转。

### 优先级二：只做少量训练规则对照

先用 4×128 与 4×1024，不重跑全部九个模型。
对学习率衰减、较小学习率后期微调、适度 weight decay 做独立对照；保留原检查点作为候选。
必要时增加两个随机种子确认排序是否稳定。
仅增加 epoch 不是第一优先级，因为已见路线的新联合状态上同样出现明显 gap。

### 优先级三：再测试有控制结构的表示/网络

在仍保留完整未来参考信息的条件下，比较显式相对姿态误差、当前误差与未来参考分别编码，或预测 nominal 控制的修正量。
这不同于简单给 MLP 增加残差连接：残差连接主要改变优化方式，不能自动填补缺失的联合状态覆盖。
任何输入变换都需另立契约/目录，并先核对教师一致性，不破坏当前 300D 试飞入口。

评估分别报告正常跟踪、恢复、尾部 p95/p99、各控制输出，以及受扰动闭环效果。
如果小网络持续位于误差–实测时延前沿，应接受这个结果，而不是削弱教师、放宽标签标准或删除困难 Validation 样本来制造“大网络必胜”。
