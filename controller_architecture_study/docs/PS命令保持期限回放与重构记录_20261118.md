# PS Hold Expiry Replay and Refactor Checkpoint

## 本轮验证了什么

上一轮十二机实测里，Drone10 的第 365 个任务是最后一次收到命令 ACK。当旧命令的保持期限到期后，普通更新仍在发布，但已经无法通过同一条过期的绝对期限。程序最终由位置偏差保护退出该机。本轮使用该次 AXU3EGB 运行日志做因果回放，并对真实 C++ 日历的单机退休接口补充回归。到期触发只存在于离线回放中。

| 事件 | 距最后一次命令 ACK | 依据 |
| --- | ---: | --- |
| 旧命令的保持期限到期 | 160.000 ms | 版本 315 的匹配观测和 160 ms 最大更新间隔 |
| 全组发布线程首次有记录的到期后唤醒 | 160.511 ms | 如果在这个唤醒检查所有飞机，Drone10 此时会有一条到期事件 |
| Drone10 第一次到期后发布自己的周期 | 168.412 ms | 只在该机发布自己的任务时检查，会比全组检查再晚 7.901 ms |
| 实际飞行保护触发 | 3,249.386 ms | 第 528 个任务采样时，位置偏差超过 8 m |

回放只在观测已经可用时更新期限，按控制版本配对，并持续使用同一命令 ACK 的绝对上限。按全组发布唤醒触发时，退出事件比历史位置保护早约 **3.09 秒**，会从第 374 个周期起停止发布 Drone10 的普通控制任务。历史日志中，这段对应 152 条入队时已超过原保持期限的拒绝、2 条忙碌丢弃，以及最终的位置保护记录。到期附近最后一次已记录的跟踪误差约 **0.120 m**。这些是原轨迹上的反事实时序结果。发布线程的 **0.511 ms** 是本次日志中的观测量，真实定时器延迟还需要在运行时测量。[回放脚本](../ps_planner_repair/replay_hold_expiry.py) · [回放原始输出](../results/ps_hold_expiry_replay_20261118_001/replay.json)

新增 C++ 回归验证了两条边界。单机退休时，已运行的整任务仍占有 DPU，返回结果不会通过下发检查，之后另一架飞机可以取走自己的任务。若命令 RPC 已在途，迟到的 ACK 仍按实际发生记录，退休的回路保持关闭。Windows 三组共 **191 项**检查通过，其中有 8 项是本轮新增。板端最新已验证运行版仍对应上一轮 **183 项 ARM 回归**。本轮未执行带到期逻辑的飞行，也没有测得悬停、制动或救回效果。[C++ 回归](../ps_planner_repair/live/live_calendar_tests.cpp) · [上一轮板端记录](PS就绪队列派发修复_20261117.md)

## 重构前应保留的边界

| 模块 | 当前入口 | 重构时应保留的语义 |
| --- | --- | --- |
| 物理保持期限 | `features/features.cpp` 的 `safe_deadline()` | 暂用采样和旧命令 ACK 计算绝对期限，并保留恰当的版本；新观测不能刷新同一条命令的最大保持期限。ACK 目前是命令加 ping 的返回代理。 |
| 任务与模型调度 | `ps_planner_repair/live/live_calendar.*`、`scheduler.cpp`、`revalidate.cpp` | 日历管理单机占用与绝对发布，派发只选择具备时间预算的任务，联合计划提交需要最新版本复核。逻辑取消不能释放仍在运行的 DPU。 |
| 执行与命令 | PS 快照中的 `adaptive_live.hpp`、`adaptive_runtime.cpp`、`local_dpu.*` | 输入归属、派发、DPU 返回、命令下发和 ACK 的因果链保留。入队直接拒绝的任务只结算一次，尚在途的命令有明确状态。 |
| 到期处置 | 本轮回放和 `LiveCalendar::retire()` 回归 | 到期时按同一控制版本触发一次，停止该机普通任务。制动、悬停、模拟器终止或恢复控制由独立路径决定，其命令归属及延迟需要单独验证。 |

建议先把**到期检测、普通调度、恢复命令**定为三个接口，再整理目录。运行入口需要在发布或提交普通命令前复核最新的版本和绝对期限；命令在途时保留实际 ACK，并避免未知状态下重复下发。若要让备用动作在期限前生效，还需要给它留出执行预算。现有 `retire()` 可以支撑调度退出验证，物理恢复策略仍待实现。[PS 源码快照和构建依赖](../ps_board_source/README.md) · [当前路线 B 交接](Route-B实现现状与交接_20261117.md)

## 复现入口

在工程根目录使用 Python 标准库。示例沿用之前的实飞原始日志，输出文件需使用新路径。

```powershell
$trial = 'controller_architecture_study/results/ps_ready_queue_board_20261118_001/revised/trial'
python controller_architecture_study/ps_planner_repair/replay_hold_expiry.py `
  --trial $trial --vehicle Drone10 --ack-cycle 365 --output .\drone10_replay_new.json
```

原始 `requests.jsonl` 的 SHA-256 为 `d40eec9786a55a639d501b35cb3aa3f9d99497f1907572a942f65b58eca6e123`。与项目中其他实测结果一样，原始日志位于被 Git 忽略的 `results/`。协作者复跑需另取同一份日志及 `execution_identity.json`。
