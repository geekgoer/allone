# 最大残差模型：追加 5000 轮训练

## 本轮范围

仅训练 `residual_mlp_h33_w1024_seed0`：237D 输入、4D 输出、33 个隐藏 Linear 层、宽度 1024，加上输出层共 34 个 Linear 层，33,835,012 个参数。

从既有最佳检查点（原训练第 595 轮，验证集 normalized MSE = 0.00023551078513264656）继续，**追加 5000 轮**。新实验编号从 1 到 5000；不是从头训练，也不是把原训练累计补到 5000 轮。恢复 Adam 动量，重新开始本次 5000 轮的学习率计划。

旧模型、教师数据、归一化参数和数据划分不修改。训练脚本启动前检查源检查点及 train/validation/normalization 的 SHA256；不读取测试集。不启动 AirSim，不量化，不训练超网或其他模型。

## 设置与保存

- FP32，单进程 CUDA，batch size 512。
- Adam，学习率 `1e-5`，按本次轮次 cosine 降至 `1e-6`；断点恢复不会重启 cosine 时钟。
- L2 weight decay `1e-5`，梯度范数裁剪 1.0。
- `early_stopping=false`：patience 字段仅为兼容现有配置格式，完全不参与停止判断。正常情况下跑完 5000 轮；OOM、驱动故障、断电等仍会中断。
- 保留原最佳检查点为新实验的 epoch 0 候选。`best_model.pt` 只在验证集改善时替换；不强行选择第 5000 轮。
- `last_model.pt` 包含模型、Adam、随机数状态、历史和本次轮次，每 10 轮、验证集改善时、以及最后一轮保存；临时文件完成后原子替换。
- 中断后重复同一命令，自动从已保存轮次继续，最多重复 9 个完整轮次及正在进行的轮次。已经完成 5000 轮后重跑，不会再追加 5000 轮。

源完整训练检查点约 406 MB。降低定期保存频率可以避免每轮写入它；验证改善时仍会立即写 best 和 last 两个完整检查点。训练目录请留出几 GB 空间。长训练的耗时取决于实际每轮速度，不承诺几小时能完成。

## 为什么暂不改残差结构

当前结构：

`h0 = ReLU(Linear(input))`

`h_next = ReLU(h + alpha * Linear(h))`，`alpha = 1/sqrt(32)`

`output = Linear(h)`

这是合法的缩放后激活残差 MLP，不是尺寸不匹配或忘了跳连的实现错误。它的局限是每次相加后都经过 ReLU，负值会被截断；恒等信息流不是无条件畅通的。

对以后从头训练的最大超网，可优先考察两层预激活残差块：

`h_next = h + alpha * W2(ReLU(W1(ReLU(h))))`

相加后不立刻 ReLU，初始化时可让末端残差层为零，从恒等块开始；也可以独立比较零初始化的可学习残差门。它们是不同候选，不是“换个写法就保证更优”。若切换现有块的激活位置、合并块或改变残差门，计算函数就改变了，不能把旧权重载入成功当作延续了旧模型。

本轮的研究问题是“现有最大、已试飞的模型是否还受训练不足影响”，所以保持结构不变，单独改变训练预算。否则无法区分结构和训练时间的作用。

参考：[Identity Mappings in Deep Residual Networks](https://arxiv.org/abs/1603.05027)、[Fixup Initialization](https://arxiv.org/abs/1901.09321)、[ReZero](https://arxiv.org/abs/2003.04887)。这些研究不构成当前控制数据上必然改善的证据。

最大模型不必在每种状态、每次闭环测试中都最好。更好的离线误差也不能抵消所有延迟影响。以后把它作为超网父网络，仍需联合训练各子网/退出头、评估权重共享的精度代价；训练一个最大网络并不能自动获得可靠小子网。

## FALCON 性能指标的数据条件

论文加权状态误差形式：

`J = 1 / sum_{k=0}^{K} ((psi_k - psi_ref,k)^T Wx (psi_k - psi_ref,k))`

这里 `psi=[p(3),v(3),q(4)]`，不是 DNN 输出相对 MPC 标签的 MSE。必须保存同一坐标系、同一参考时钟上的实际/参考位置、速度、四元数，以及采样时间。比较前确定并公开 Wx、K、采样和跨窗口汇总方法；四元数需归一化并对齐正负号。

本轮已为 `control_value_probe` 的新 trace 增加实际四元数、参考速度、参考四元数和参考相位；setup 记录字段约定。未来通过这个更新后的入口采集，可以从原始记录计算上述状态成本；**既有短窗 trace 缺失的姿态和参考速度不能事后恢复**。这次不重新运行那些飞行实验，旧输出不修改。因采集代码版本已变，新试验须使用新输出目录，不把新日志混进旧实验。

这也不等于精确重现原论文所有数值：论文未公开完整 Wx 数值，当前时间是主机采样/提交代理，不是硬件执行器实测响应时间。`C(c,T,R,epsilon,theta)` 是要用闭环 J 数据重新拟合的性能模型；旧 12D/FPGA 的拟合结果不能直接用于新 237D/GPU 控制器。

其他飞行入口没有因这次修改自动获得这些字段。未来性能函数正式实验应统一使用完整状态采集契约，而不是只读某个 summary 中的位置 tracking MSE。
