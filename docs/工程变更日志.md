## 2026-11-22 · 分段 DNN 与到期处置

- **问题与改动**  共享 DPU 上，整网任务可能阻塞后来就绪的急任务。用 `export_segmented_mlp.py`、`compile_segmented_dnndk.py` 和 `benchmark_segments.cpp` 实现模型 ID 11 的双 kernel 原型。`prepare_hold_expiry.py` 与 `live_calendar` 接入按控制版本检测旧命令到期并退出该机普通调度。
- **验证**  AXU3EGB 上 960 组整网与两段 INT8 输出逐项一致。额外耗时中位数 21.33 μs。双任务基准验证了提前为急任务留切口的收益。到期处置当轮在 Windows 和板端 ARM 各通过 204 项回归，覆盖在途推理、迟返 ACK 和单机退出。
- **证据与待办**  `results/ps_segments_20261122_001/`。分段当轮在独立基准中运行，闭环整网派发待另做负载验证。到期退出后的实际备用控制仍待验证。[分段原型和计时](../controller_architecture_study/docs/Route-B分段DNN与保持期限_20261122.md#实验二将同一-dnn-真正切开)

## 2026-11-22 · 可分段机会与派发拒绝复算

- **问题与改动**  要确认十二机的丢弃是否由连续 DPU 占用造成。`replay_dnn_segments.py` 和 `audit_segment_opportunities.py` 用实测时戳比较整网派发、推迟整网和切段预留。日历日志新增拒绝当时使用的模型成本、命令预留和剩余预算。
- **验证**  三轮累计检查 32,624 次 ID 11 起跑，局部窗口内未发现只有切段才能满足期限的任务对。修订轮 694 次模型预算拒绝均被复算，其中 664 次若采用初始模型成本会通过这道检查。该数字是反事实准入结果。诊断版在 Windows 和板端 ARM 各通过 207 项回归。
- **证据与待办**  `results/ps_segment_opportunities_20261122_001/final_audit.json`。根据分阶段实测查清模型成本中包含的派发延迟。[机会与拒绝复算](../controller_architecture_study/docs/Route-B分段DNN与保持期限_20261122.md#实验四三轮十二机日志中的可预测切口)

## 2026-11-22 · 分离派发等待与模型成本

- **问题与改动**  诊断基线有 80 条从派发到本地推理返回超过 3 ms，其中 62 条以日历取锁为主。`live_calendar` 增加可选的 `separate_dispatch_service`。派发用获得日历锁后的时钟复核，选定模型放不下时，自适应模式最多尝试一次已经允许的最快档。
- **验证**  十二机、20 ms、32 秒三次完整运行分别按时交付 18,750、18,036、19,014 条，各发布 19,200 条。只复检原档的一轮在最后检查额外丢弃 1,090 条。修复后有 2,505 条当场换档，2,500 条按时交付。三轮均通过 144 道门，严格时序均未通过。Windows 和板端 ARM 各通过 210 项回归。另一次启动空窗约 1.056 秒，零推理并触发 12 机退役，单独保留。
- **证据与待办**  `results/ps_dispatch_timing_20261122_001/`。单次顺序对照的收益仍需重复试验，队列锁竞争与 DNNDK 尾延迟需分别跟踪。[十二机分阶段计时](../controller_architecture_study/docs/Route-B分段DNN与保持期限_20261122.md#实验五十二机闭环分阶段计时)

## 2026-11-22 · 规划快照持锁优化

- **问题与改动**  原快照在锁内边构建边检查，发现后面一架机的观测不可用时会丢掉前面已经构建的内容。`snapshot_precheck` 先验证全组观测，再构建快照。`snapshot_precheck_bench.cpp` 对照同一十二机日历的快照与用时。
- **验证**  Windows 和板端 ARM 各通过 210 项回归。板端独立基准中，最后一架缺少观测时，耗时中位数从 1.977 ms 降至 10.5 μs。可用快照的 36 条任务义务逐项一致。同二进制飞行对照的前 5.82 秒内，派发等锁 P99 从 0.556 降至 0.420 ms，按时交付从 3,467 降至 3,396 条。全程分别通过 135 和 144 道门。关闭轮一架退役，两个全程的调度负载因此不同。
- **证据与待办**  `results/ps_snapshot_precheck_20261122_001/comparison.json`。保留开关供重复试验，继续检查命令下发前丢弃。[快照持锁与闭环对照](../controller_architecture_study/docs/Route-B分段DNN与保持期限_20261122.md#实验六规划快照的两步检查)
