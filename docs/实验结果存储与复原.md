# 实验结果目录与复原说明

`controller_architecture_study/results/` 收录近期 PS 实测、调度回放、正在被工具读取的模型和数据、冻结交付包。即使名字较旧，场景生成、模型复跑和历史验证也可能依赖其中的路径。当前执行证据可从[十二机上板报告](../controller_architecture_study/docs/PS就绪队列派发修复_20261117.md)和[Drone10 回放](../controller_architecture_study/docs/PS命令保持期限回放与重构记录_20261118.md)进入。

`archive/local/controller_architecture_study/results/` 收录早期实验的原始记录。里面最大的几类是长航线试验的 `traces.json`、CPU 等待与线程切换的 Windows `.etl`、用于查看跟踪堆栈的 `.etl.NGENPDB` 符号缓存，以及历史交付包。保留的原始轨迹通过 NTFS 压缩腾出空间，现有程序可从原路径读取。资源管理器的“大小”仍表示解压后的字节数，实际占用看“占用空间”。

## 需要继续缩小空间时

当前使用的 `ps_unified_handoff_20261116_004`、`ps_migration_handoff_20261116_002` 和 `ps_verified_handoff_20261116_002` 都有工具读取其解包路径。其他版本有独立的 SHA-256 或编译验收记录，其中一些解包目录也包含独有的测试二进制或构建诊断。判断整轮实验能否删除时，先核对引用和完整内容。去掉受引用的派生副本时，需要给工具提供已验证的恢复入口。旧飞行的原始日志、不同训练阶段的权重和失败试验证据仍可用于复核。
